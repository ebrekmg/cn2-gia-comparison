## CN2 GIA 和 CN2 GT 有什么区别

搬瓦工有两代 CN2 产品，看测评时最容易被混在一起。CN2 GT 只保证部分路段走电信 CN2 网络，进出骨干网时仍要汇入普通线路，晚高峰有拥堵和丢包的可能；CN2 GIA 则是全程走 CN2 精品网的专属通道，优先级和稳定性都高一个档次。曾经的 GT 明星机房 DC8 已经下线，现在官方主推的 CN2 线路集中在洛杉矶：DC6（CN2 GIA-E）和 DC9（CN2 GIA）。
